# Simple Contact Book

A simple Node.js contact book app built with Express and MongoDB.

## Features

- Create, read, update, and delete contacts
- Store contact data in MongoDB
- Simple REST API

## Tech Stack

- Node.js
- Express
- MongoDB
- Mongoose

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```

3. The API will be available at:
   ```text
   http://localhost:3000
   ```

## Project Structure

```text
src/
  server.js
  models/
    Contact.js
```

## Environment

Make sure your MongoDB connection is configured before running the app.
